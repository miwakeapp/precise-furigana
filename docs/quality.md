# Alignment quality

Coverage, reconstruction, and the segment invariants are checked mechanically for every record. Linguistic correctness is not: inventories are incomplete, several allocations can be defensible, and a plausible sound change can be wrong for a particular word. The regression fixtures target hard cases rather than a random sample. Evidence was reviewed by AI agents against cited sources, not by a lexicographer.

## Deliberately unresolved

- Grouped because no evidence divides the sound, though the pronunciation is known: <span lang="ja"><ruby>海女<rt>あま</rt></ruby></span>, <span lang="ja"><ruby>硝子<rt>ガラス</rt></ruby></span>, <span lang="ja"><ruby>金糸雀<rt>カナリア</rt></ruby></span>, <span lang="ja"><ruby>寄席<rt>よせ</rt></ruby></span>, <span lang="ja"><ruby>寿府<rt>ジュネーブ</rt></ruby></span>, <span lang="ja"><ruby>土筆<rt>つくづくし</rt></ruby></span>, <span lang="ja"><ruby>一日<rt>つきたち</rt></ruby></span>.
- <span lang="ja"><ruby>河<rt>かわ</rt></ruby><ruby>原<rt>ら</rt></ruby></span> follows [word-local support](https://en.wiktionary.org/w/index.php?oldid=92246152#Japanese), though character readings also permit <span lang="ja"><ruby>河<rt>か</rt></ruby><ruby>原<rt>わら</rt></ruby></span>.
- In <span lang="ja"><ruby>幼<rt>おさな</rt></ruby><ruby>馴染<rt>じ</rt></ruby>み</span> (<span lang="ja">おさなじみ</span>), the longer <span lang="ja">おさななじみ</span> does not show which character lost <span lang="ja">な</span>. [The <span lang="ja">なみ</span>‐<span lang="ja">あし</span> analysis](https://kotobank.jp/word/%E4%B8%A6%E8%B6%B3-589744) does not divide <span lang="ja">常歩</span> either.
- A zero never gets a sound of its own: <span lang="ja"><ruby>三〇<rt>さんじゅう</rt></ruby><ruby>日<rt>にち</rt></ruby></span> and <span lang="ja"><ruby>１００<rt>ひゃく</rt></ruby></span> are single groups, because a numeral divides only at its nonzero digits. No source assigns a sound to 〇 alone, and [Wiktionary's own example](https://en.wiktionary.org/w/index.php?title=%E3%80%87&oldid=92474196) rubies <span lang="ja">二</span>〇〇<span lang="ja">七</span> as a whole; dividing at nonzero digits is this project's convention, not an attested one.
- <span lang="ja"><ruby>下<rt>した</rt></ruby><ruby>放<rt>っぱな</rt></ruby>れ</span> follows KANJIDIC's prefix <code lang="ja">-っぱな.し</code>, which does not prove <span lang="ja"><ruby>下<rt>したっ</rt></ruby><ruby>放<rt>ぱな</rt></ruby>れ</span> wrong.

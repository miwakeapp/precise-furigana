# These docs are mainly for coding agents

The code for this project was written by GPT-6 Astra first, and then Claude Opus 5.5. I, Domenic Denicola, have not really looked at it.

The agents generated this documentation. It is not that readable as a human; you'd be better off having your own agent summarize it, or summarize the code. But it is kept here for the benefit of future agents that might work on this project.
